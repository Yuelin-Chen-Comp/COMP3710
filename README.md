# COMP3710 — Pattern Analysis

Coursework for COMP3710 (Pattern Analysis), University of Queensland.

## Contents

- **`fractal_tree.py`**, **`Untitled3 (1).ipynb`** — Lab 1: Newton fractals in PyTorch.
- **`DEMO2/`** — Lab Demonstration 2 (Pattern Recognition). See [`DEMO2/README.md`](DEMO2/README.md)
  for the full breakdown: DFT, Eigenfaces (PCA + Random Forest), CNN classifiers, ResNet-18 on
  CIFAR-10 (DAWNBench), and the VAE/UNet/GAN recognition tasks.

## Environment

Python 3.11+, PyTorch (with CUDA on the Rangpur cluster / MPS on Apple Silicon), torchvision,
scikit-learn, matplotlib, numpy. Individual notebooks list any extra dependencies they need.
